# Adventure Learning World

A kid-friendly educational adventure web app inspired by the supplied reference screenshots.

## Features
- Five learning worlds
- Sequential world unlocking
- Demo unlock-all mode
- Interactive mini quests
- Hints
- Points and stars
- Badges
- LocalStorage progress persistence
- Responsive mobile/desktop UI
- Reset progress button

## Run

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

The app is frontend-only and does not require an API key or database.
